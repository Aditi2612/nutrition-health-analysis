# 🥗 Nutrition & Health Risk Analysis

A SQL-based data analysis project exploring nutritional 
patterns, hidden health risks, and food quality across 
168 food items and 16 categories.

---

## 📌 Project Objective

To analyze a real-world nutrition dataset using MySQL and 
extract actionable health insights — identifying the 
healthiest foods, hidden fat and sugar risks, and building 
a custom health scoring model.

---

## 🛠️ Tools Used
- **MySQL** — data cleaning, analysis, custom scoring
- **MySQL Workbench** — query execution environment

---

## 📂 Project Structure
- `nutrition_analysis.sql` — all queries with documented 
   business questions and findings
- `nutrition_insights.md` — detailed insights report
- `README.md` — project overview

---

## 🔍 Key Business Questions Answered

| # | Question |
|---|----------|
| 1 | Which food categories are most calorie-dense? |
| 2 | Which foods deliver the most protein per calorie? |
| 3a | Which moderate-calorie foods hide saturated fat risks? |
| 3b | Which foods are hidden sugar bombs? |
| 4 | How do categories compare nutritionally? |
| 5 | Which foods score highest on an overall health model? |
